# Bilinear matrix-multiplication records

Reproducible exact bilinear matrix-multiplication certificates and independent
verifiers.

## Records

| Tensor | Field | Rank | Certificate |
|---|---|---:|---|
| `<15,15,17>` | GF(2) | 2,256 | [`records/15x15x17`](records/15x15x17/) |

Python and C++ verifiers, machine-readable metadata, and SHA-256 digests.
